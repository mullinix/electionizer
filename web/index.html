// OpenFEC API key //

Stored only in this browser. DEMO_KEY is rate-limited (~40/hr).

Get a key: api.open.fec.gov

// Open States API key //

Optional. Adds state legislature incumbents only (not a full ballot — no challengers) via people.geo where FL/AZ scrapers don’t apply, plus roll-calls on candidate detail. Free tier 10 req/min.

Get a key: openstates.org

// FollowTheMoney API key //

Optional. State campaign-finance totals for non-FL candidates (OpenSecrets / FollowTheMoney.org). Free key via a myFollowTheMoney account. Data published through 2024; needs Wisp or CORS for the API host.

Register: followthemoney.org · API docs

// CourtListener token //

Optional. Improves rate limits for judicial Decisions (opinions) and law-practice history via Free Law Project. Anonymous access often works at low QPS. Never required for legislators.

Register: courtlistener.com · API docs

// Google Civic API key //

Optional. Multi-state full ballot contests (candidates + measures) via the Voting Information Project when a feed is live — often only ~2–4 weeks before an election. Used for AZ and other states without rich official filings (skipped when FL/NC/MD filings already load). Home form optional street address improves precinct match (else ZIP centroid). Free GCP key; ~25k queries/day.

Enable API + create key: Civic Information API · docs

// AI verdict (optional) //

After a ballot loads, Grok scores every candidate and measure (early pass: identity + live web/X search). The list sorts by personal fit; Scorecard tabulates those scores by party for each office. Click a name for the full verdict. Home voter profile (1–5 Likert, add-your-own entries, export/import the list without ratings) remaps scores (dislike 80 → 20) on a blue→gold heatmap. Profile stays in this browser. Key stays in this browser. Needs Wisp. Cached until you hit refresh data / refresh score on the ballot, a race, or a name. L6 contrast notes under Scrutiny still run separately.

Keys: console.x.ai · platform.openai.com

3 at a time. 1 = sequential. Local Wisp handles more than the public instance.

// Wisp proxy (libcurl.js) //

Used for AZ/FL chamber HTML, FL DOS extract, and FL amendment detail. Browser loads libcurl.js and tunnels HTTPS (E2E TLS) through Wisp. Default: wss://wisp.mercurywork.shop/ — public, shared, and rate-limited (heavy FL/AZ use may stall or fail). For reliable local use: run ./scripts/run-static.sh then This origin (Wisp on the same host as the static files). Clear the field and Save to disable Wisp.

// CORS proxy (fallback) //

Optional fallback when Wisp is unset. Example: https://corsproxy.io/?

// Florida DOS TSV (optional) //

Live DOS Candidate Tracking is fetched via Wisp/libcurl.js (same as the native app). Upload or ship a TSV only as offline fallback. See web/data/README.md.

No TSV stored.

// Cached ballots & responses //

Responses stay until you reload them (refresh data / score on the ballot, a race, or a name) or clear here. This wipes IndexedDB (last ballot, FEC/DOS/chamber HTTP bodies, TreFin dumps, verdicts) and hides the home “Last ballot” reopen offer. The next ZIP run fetches live again. Does not remove API keys, Wisp/CORS URLs, theme, mode, cycle, or FL DOS TSV upload. Google Civic VIP still expires in 12h (their guideline).
